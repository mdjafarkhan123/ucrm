# V3 — Botanical workspace

A separate desktop color study copied from v2. V1 and v2 are unchanged. Same job data, sections, preview editors and photo modal.

The convention is role-based color: forest brand/actions, neutral warm surfaces, explicit blue Upcoming states, green Completed states, and amber pending sign-off. Category icon accents are decorative recognition aids, not status indicators. Text labels always carry the meaning. A softly tinted identity/summary container connects the job header; the original wide work column and narrow supporting column remain.

Sources: [Material color roles](https://m3.material.io/styles/color/the-color-system), [Atlassian accent colors](https://atlassian.design/foundations/color/accents), and [Atlassian color foundations](https://atlassian.design/foundations/color). The botanical palette and exact composition are our adaptation, not competitor behavior or a user-tested result.

Desktop Chromium checks at 1440px and 1280px pass: no overflow or browser errors, five visits, title editor/apply/reset, photo modal/Escape. Visually inspected the full page. This is not a full accessibility audit; phone refinement and complete modal/scenario migration remain deferred. Sample map/photos are illustrations. Nothing sends or persists to a backend.

Serve the `design-previews` parent on port 4189; open `/job-details-v3/`. The page links back to v2.

## Balanced typography revision

At Jafar's request, v3 now uses approximately 15px main content, 13px supporting detail, 18px section headings, and medium/semibold emphasis for names and controls. Secondary text is darker; small dates, table headings, billing details and activity metadata have been increased. Decorative initials and brand/map labels retain smaller sizes. The supporting column is slightly wider to accommodate readable billing text. Desktop overflow and preview interaction checks pass at 1440px/1280px. Outdoor legibility is not yet proven on a real device.
