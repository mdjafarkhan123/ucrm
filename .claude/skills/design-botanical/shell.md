# Approved Botanical shell

Read the [approval record](../../../docs/design/botanical-v3/sidebar-approval.md) for exact sources,
values, states and exclusions. Shared foundations remain in the [starter guidance](../../../docs/design/botanical-v3/README.md).

## Sidebar

Variant 2 revision 2 is approved. Preserve semantic grouped links, visible labels by default,
`aria-current`, optional desktop collapse, independent navigation scrolling with a reachable collapse
control, and reachable phone navigation with contained focus, Escape dismissal and focus return.
Preserve server-resolved access and existing routes. Use shared behaviour and app token/rem conventions.

## Header/layout

Header B revision 4 is approved. Desktop web is primary. The shell body owns the shared outer inset,
so header and page content align automatically. Keep inner control/panel padding local. Header stays
outside scrollable page content; retain sidebar collapse and reachable phone navigation. Preserve fixed
save-bar coordinates and reserved bottom space when changing shell insets. This approval covers the shell,
not placeholder content, universal menus/dialogs, search internals or a dark palette.
