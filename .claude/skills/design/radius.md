# Radius

| Element | Radius |
|---|---|
| Buttons, fields, rows, sidebar items | 8 (`--radius-base`) |
| Cards, tables, panels | 16 (`--radius-large`) |
| Pills, avatars, count chips | full (`--radius-circle`) |
| Icon tiles | 6 (24 tile, `--radius-tile-small`), 8 (32 tile, `--radius-base`), 10 (40 tile, `--radius-tile-large`) |
| Key hint (⌘K) | 4 (`--radius-small`) |
