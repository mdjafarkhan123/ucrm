# Classic theme redesign — now

**Goal:** Redesign the whole application with researched new Classic concepts: premium, polished, modern,
colorful, clear and calm. Multicolor icons are welcome. Build one approved screen at a time; keep an existing
idea only when it works best.

[Behavior rules](../../../docs/classic-theme-redesign-behavior-contract.md#behavior-that-must-not-change).

in the [Save bar note](parts/b4-save-bar.md).
