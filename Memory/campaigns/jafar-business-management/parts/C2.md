## Notes

Approved by Jafar 2026-10-08:
- Calls: time + length. Follow-ups: a day, time optional.
- Default reminders: call — email 1 day before, in-app + email 15 min before; day-only follow-up — in-app 9:00 that day; timed follow-up — in-app 15 min before. Editable per item; defaults in My preferences.
- Reminder emails go to the person's sign-in email (not the alert recipients).
- Time zone saved in My preferences, filled from the browser.
- A passed call asks "How did it go?": Held (set next step) · They didn't show (creates "Reschedule the call" due today) · Cancelled.
- Busy blocks one-off only; weekly hours come with E1.
- Calendar: Day/Week/Month on computer, day-by-day list on phone; only sales calls, follow-ups, Busy. Sales Day = one-day Week grid (time down the page).
- Shared grid (option B): one Week grid, Month grid and top bar used by both calendars; each keeps its own cards.

- Google Calendar's reminder model (a list of "channel + how long before", with defaults in settings) is the proposed pattern; Pipedrive/HubSpot activities for calls with a time vs date-only tasks.
- Owners don't exist yet (D3 waits for C2): everything is Jafar's, but store an owner column so D3 only fills it in.

Performance design (Ready, 2026-10-08):
- Grows: calendar entries (~20 calls/day → ~7k/yr), Leads with a dated next action (assume ≤50k), reminders (~3 per item).
- Shape: `platform_calendar_entries` (call | busy, starts_at/ends_at, owner null = Jafar) indexed on starts_at; partial index on Leads' `next_action_due_on`; `platform_reminders` derived by triggers (any next-action or call change deletes pending rows and recreates them in the same transaction), partial index on fire_at where unsent. Worker claims with a 5-min lease and `for update skip locked`, batch 50; email via outbox key `platform-reminder:<id>`, in-app via owner notification with correlation id = reminder id; reminders over 60 min late are skipped. Calendar read = one RPC for a ≤42-day window, capped and flagged.
- A BEFORE trigger clears a next action's time, call link and custom reminders when any older writer replaces the text/date without setting them.
- Verify: EXPLAIN on window read and claim with 50k Leads/10k entries seeded; window read < 50 ms; a moved call leaves no pending row for the old time; phone build LCP/INP on the calendar page.
