## Evidence and practical limits

Read-only live inspection used the existing Contractor owner test login, the Jobs list, and Job #1 (`fd9e7a6d-393f-46a5-bc11-1c6d6cb20e99`). It confirmed the real shell, empty labor/expenses, checklist, past visits, notes/files, stale signatures, changed report, totals/costing and payment-stage/reminder/tax controls. No live record was changed. Permission variants were cross-checked against the current component gates, not established by impersonating every role.

- `node design-previews/job-details/verify.cjs`: 13 scenes at 1440px/390px, 40 page action previews per width, title draft save/cancel/reset, mobile navigation, Escape dismissal, no document overflow or browser errors.
- Additional browser checks: restricted scene exposes no customer prices; visit scheduling actions hidden for field; final-visit completion → close → reopen; staged instruction save; photo arrow keys.
- Axe WCAG A/AA checks: no findings on the populated desktop page or signature dialog after contrast corrections. This is bounded automated evidence, not a blanket accessibility certification.
- Desktop/phone screenshots inspected for header/navigation, populated/long/restricted/recurring content, dialogs, editing bar and finances. Contrast and toast placement were corrected; the toast now clears the pinned save bar.
- SCSS compilation and focused Prettier check pass. App build/check are not needed because this standalone demo changes no app code.

The current implementation omits some older contract aspirations, including job deletion/create-similar commands and bulk move/delete controls. They were not added as invented redesign features. Destination pages and real backend validation are outside this job demo. Jafar is approving visual completeness and the preview interactions; production implementation and user/traffic capacity are unverified.
