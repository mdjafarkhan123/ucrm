## Notes

- Design (HubSpot/Pipedrive "log activity" timeline): one history per Lead — "Lead added" and "Application
  submitted" come from their own records; notes, logged contact, status changes, next action set/done, and
  Application linked/unlinked are history rows. Logged contact: direction (we contacted them / they replied or
  contacted us), channel, optional which saved contact detail, when (not in the future), summary; an outgoing
  call also takes the contractor call outcomes. Notes and logged contact can be edited and deleted; automatic
  rows cannot. Marking the next action done asks for the next one (Pipedrive).
- An Application links to one relationship at most; linking one already linked elsewhere is refused.
- Editing a Lead's details (LeadForm in edit mode) is not in B2 — added to the stage as B2b.
- Speed: page = one request (details + newest 50 history rows, "Show older" by cursor); index
  (relationship_id, occurred_at desc, id desc). Assume ≤1,000 rows per Lead, 20,000 Leads. Picker loads on
  hover; Applications search is a bounded ilike (hundreds of rows today; add trigram past ~50,000). Verify:
  EXPLAIN on a Lead with 2,000 history rows; phone lab load.
